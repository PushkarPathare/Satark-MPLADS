# SATARK — AI-Powered Public Development Project Monitoring

**SATARK** is a project monitoring platform designed to improve the transparency and tracking of public development projects under the Members of Parliament Local Area Development Scheme (MPLADS).

The platform aims to make project information easier to monitor, identify potential delays and support data-driven decision-making through a centralized interface.

## 🚀 Live Demo

[View SATARK](https://satark-mplads.vercel.app/)

## 🎯 Problem Statement

Monitoring public development projects can involve reviewing scattered information about project progress, implementation status and expenditure. This can make it difficult to identify issues early and track project performance efficiently.

SATARK aims to simplify this process by bringing project monitoring information into a single platform.

## ✨ Key Features

- **Centralized Project Monitoring:** Organizes public development project information in one place.
- **Project Status Tracking:** Helps users review project progress and implementation status.
- **Delay and Risk Awareness:** Supports the identification of projects that may require additional attention, where supported by the implemented features.
- **Data-Driven Insights:** Presents project information to support monitoring and decision-making.
- **Accessible Dashboard:** Provides a centralized interface for exploring project-related information.
